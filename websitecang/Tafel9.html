Das Kleingedruckte der Cannabis-Teillegalisierung
09

KEIN „CANNABIS-CLUB FÜR EIN WOCHENENDE“

Gesetzliche Grundlage: § 16 KCanG

Eine Anbauvereinigung ist rechtlich nicht als kurzfristiger Cannabis-Shop gedacht.

Für Anbauvereinigungen gelten bestimmte Mitgliedschaftsbedingungen. Bei Vereinen, die als eingetragene Vereine organisiert sind, müssen die Satzungen insbesondere eine Mindestdauer der Mitgliedschaft von drei Monaten vorsehen.

Das bedeutet: Man kann nicht einfach für ein Wochenende Mitglied werden, Cannabis beziehen und anschließend die Mitgliedschaft wieder beenden – das gesetzliche Modell ist auf eine längerfristige Mitgliedschaft ausgelegt.

Kurzfristiger Einkauf

Geschäft betreten → Produkt auswählen → bezahlen → mitnehmen.

Eine solche kurzfristige Kundenbeziehung ist nicht das Modell einer Anbauvereinigung.

Anbauvereinigung

Mitglied werden → Vereinsregeln beachten → Mitgliedschaft aufrechterhalten → gesetzlich geregelte Abgabe.

Die Mitgliedschaft ist auf eine längerfristige Teilnahme angelegt.

Beispiel: Besuch in der Stadt

Paul ist nur für ein Wochenende in einer anderen Stadt. Er entdeckt dort eine Anbauvereinigung und möchte spontan für dieses Wochenende Mitglied werden.

Eine solche kurzfristige Mitgliedschaft ist mit dem vorgesehenen Vereinsmodell nicht vereinbar.

Frage an die Besucherinnen und Besucher

Wie unterscheidet sich eine Anbauvereinigung eigentlich von einem kurzfristig zugänglichen Cannabis-Fachgeschäft?
